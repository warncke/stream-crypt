# Prompting Work Flow

Using an AI platform, such as https://deepseek.com/, or your own chosen inference provider, use the following workflows to modify the project.

## Revising the Technical Specification

`technical-specification.md` is the output of a prompt using `system-design-agent.md` with `TECHNICAL SPECIFICATION: ${technical-specification.md}` appended to it.

## NPM Project Creation

To output the entire npm project directory for `technical-specification.md` use the prompt `npm-project-creation-prompt.md` with `TECHNICAL SPECIFICATION: ${technical-specification.md}` appended to it.

## Git Workflow

**NEVER** commit a change to any npm project file in the same commit as a change to `technical-specification.md` or ANY prompt file.

ANY CHANGES to `technical-specification.md` or ANY prompt file MUST BE single file commits.

When making ANY CHANGES to `technical-specification.md` or ANY prompt file, the complete npm project directory, generated by the prompt `npm-project-creation-prompt.md` with `TECHNICAL SPECIFICATION: ${technical-specification.md}` appended to it MUST pass all unit tests, MUST NOT delete or modify any existing unit test, and MUST include new unit tests that provide at least 90% coverage on any new code that has been added as compared to the base state of the git repository.
